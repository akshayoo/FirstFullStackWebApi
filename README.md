# tConsole

tConsole is a modern console management application built with **React**, **Next.js**, and **FastAPI**. It provides a unified interface for managing backend operations, monitoring services, generating reports, and accessing integrated AI-assisted features.

## Features

* Modern web interface built with React and Next.js
* FastAPI backend for high-performance APIs
* Dashboard for application management
* Lab process management automation
* Report generation and management
* Integrated AI chat assistant
* Retrieval-Augmented Generation (RAG) for knowledge retrieval

## Technology Stack

### Frontend

* JavaScript
* React
* Next.js

### Backend

* Python
* FastAPI
* Uvicorn
